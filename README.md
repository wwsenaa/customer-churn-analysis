📊 Müşteri Kaybı Analizi ve Tahmini

Bu proje, müşteri kaybı (Customer Churn) davranışlarını analiz etmek ve makine öğrenmesi modellerinin performanslarını karşılaştırmak amacıyla hazırlanmıştır.

🛠️ Kullanılan Teknolojiler
- Python
- SQL
- Power BI
- Pandas, Scikit-learn, XGBoost

📈 Proje İçeriği
Power BI raporu üç sayfadan oluşmaktadır:

- Genel Bakış: Müşteri kaybı oranı, gelir kaybı ve temel göstergeler.
- Segment Analizi: Sözleşme türü, müşteri süresi ve ücret gruplarına göre analizler.
- Model Performansı ve Risk Analizi: Model metrikleri ve özellik önem analizi.

 🤖 Kullanılan Modeller
- Logistic Regression
- Random Forest
- XGBoost
- XGBoost + SMOTE

Modeller Precision, Recall, F1-score ve ROC-AUC metrikleriyle karşılaştırılmıştır.

🎯 Amaç
Müşteri kaybını etkileyen faktörleri incelemek, model performanslarını değerlendirmek ve bulguları etkileşimli bir dashboard ile sunmak.
